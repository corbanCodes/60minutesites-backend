Why the agent is separate from the script

One script, several agents. The same napkin pitch can run with a calm voice for restaurants and a brisker one for bars, or hand to different people depending on who is on shift. Splitting them means editing the script once updates every agent reading it, which is what happens now when you save on step 9.

It also means an agent is cheap to throw away. If one sounds wrong, build another and point it at the same script rather than unpicking the one you have.
